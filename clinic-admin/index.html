01 · 상병코드 정비

입력한 상병코드, EDI 표준형으로 한 번 더

KOICD 상병마스터 · KCD-9 (2026-01-01 시행 — 확인 필요) 심평원 심사조정 #1 = 상병 부적합

EMR에서 뽑은 상병 대장을 올려두기만 하면 — 마침표·공백 섞인 입력형은 EDI 표준형(M545)으로, 같은 명세서 안의 중복은 정리, 비U 주상병 없이 홀로 선 한의 병증 U코드는 표시, 그리고 최신 개정판 마스터에 없는 코드는 미수록으로. 청구 누르기 전 5분의 점검입니다.

처음이신가요? 한방 다빈도 10건(요통·오십견·염좌·U코드 등)으로 정비 결과를 미리 보실 수 있습니다.

02 · 자보 심사결과 정산

심평원이 무엇을 조정했는지, 명세서 단위로 대조

자동차보험진료수가 기준 (국토교통부 고시) 심평원 자보 심사 · 이의제기

2013년 7월부터 자보 진료수가는 병원이 심평원(HIRA)에 명세서를 청구하고 심평원이 심사결과통보서를 보내는 구조입니다. 조정에 대한 이의제기도 보험사가 아닌 심평원에 합니다. 청구 명세서 export와 심사결과 파일을 올리면 — 명세서번호+행위코드로 줄마다 청구 vs 인정을 대조하고, 조정사유별·월별로 묶어 드립니다. 같은 사유가 반복되면 다음 달에는 미리 피할 수 있습니다.

명세서 5건 · 행위 18줄 샘플(예시) — 동일부위 중복·추나 횟수 한도·첩약 처방일수·경상환자 4주 진단서 등 실제 조정 패턴을 대조표로 보여드립니다.

01 파일 대조 — 청구 명세서 ⨝ 심사결과통보

병원 → 심평원 자보 진료수가 명세서 청구 → 심평원 심사결과통보 → 조정 확인 → (필요시) 심평원에 이의제기. 보험사·공제조합은 심평원 결정에 따라 지급합니다.
두 파일을 올리면 명세서번호+행위코드로 결합한 대조표가 표시됩니다.

※ 조정사유는 예시 분류(상병-처치 부위 불일치 · 동일부위 중복 산정 · 추나 횟수 한도 · 첩약 처방일수 · 경상환자 4주 진단서 미제출 · 통원기간 초과 · 초·재진 진찰료)로 묶습니다. 실제 심사결과통보서의 사유 표기를 우선하며, 이의제기 기한은 통보서 기준으로 확인하세요.

상병 마스터 업로드 — KOICD

KOICD에서 내려받은 상병마스터(xlsx). 컬럼 예: 상병기호 · 한글명 · 영문명 · 완전코드구분. 올린 뒤 헤더를 매핑하면 정비·검색·AI 탭이 이 표를 기준으로 동작합니다. 공개 참조표이므로 이 브라우저(IndexedDB)에만 보관됩니다.

행위·수가 마스터 업로드 — 심평원

심평원 행위 급여·비급여 목록 및 수가 마스터(xlsx). 컬럼 예: 수가코드 · 한글명 · 단가 · 분류 · 급여구분 · 자보구분. 올리면 자보 정산의 예시 수가표와 검색 결과가 실제 코드로 바뀌고, 급여/비급여/자보 표시가 함께 나옵니다.

한의사·간호사가 적은 진료 메모를 그대로 붙여넣거나 음성으로 받아쓰면 — AI가 상병(KCD)·한의 병증 U코드·행위 코드 초안을 한꺼번에 골라드립니다. 추천마다 왜 이 코드인지 근거와 조정 주의점(상병-처치 부위 일치, 추나 횟수 한도, 경상환자 4주 진단서, 첩약 처방일수, 초·재진 진찰료)이 함께 나오니, 원무팀은 맞는지 확인만 하면 됩니다. 결정은 사람이, 검색은 AI가.

처음이신가요? "교통사고 후 경추·요추 통증" 메모로 — 메모 한 줄에서 청구 가능한 코드들이 어떻게 한 번에 나오는지 보여드립니다.

01 진료 메모 입력

입력 내용은 ai.pb.gurum.se 로 전송되며 저장되지 않습니다. 실제 환자 정보는 입력하지 마세요. 예시 모드는 아무것도 전송하지 않습니다.

02 추천 결과 예시 모드

메모를 입력하고 코드 추천을 누르면 결과가 여기에 표시됩니다.

※ AI는 찾아드리는 일까지만 합니다. 추천 코드는 예시 목록(내장 발췌·예시표) 기준이며, 코드 검색 탭에서 마스터를 업로드하면 마스터에 있는 코드만 제안합니다. 자보는 건강보험 행위 코드를 그대로 쓰고, 교통사고 환자에게는 비급여를 제안하지 않습니다. 청구 결정은 원무팀의 몫 — 실제 청구 전에 상병코드 정비·자보 정산 탭에서 한 번 더 확인해주세요.

08 · 면허·자격 갱신

"다음달이 신고 기한이에요" — 그 전화, 이제 안 옵니다

의료법 §25 · §30 한의사 3년 · 간호사 3년 · 보수교육 매년

의료인 면허는 만료되지 않지만, 면허신고(의료법 §25)는 사람마다 다른 날짜로 3년마다 돌아옵니다 — 마지막 신고일 + 3년. 50명이 넘어가면 머리로는 못 외우고, 한 명만 놓쳐도 행정처분이 됩니다. 명부에 신고일만 등록해두면 — 기한을 자동 계산하고 6개월 전부터 알림, 면허증 사진을 찍으면 날짜를 자동으로 읽어 입력합니다.

브라우저 주소창 없이, 독립된 앱처럼 열려요. 대시보드·양식은 오프라인에서도 동작하고 — 행정실 데스크톱이든 외근 중 휴대폰이든 바로 켜집니다. 무료이고, 설치 파일도 없습니다 — 즐겨찾기를 한 단계 발전시킨 것뿐이에요.

01 · Safari에서 열기

아래쪽 도구 줄 가운데의 공유 버튼(↑가 그려진 사각형)을 탭합니다.

02 · 메뉴에서 선택

스크롤해서 "홈 화면에 추가"를 탭합니다.

03 · 이름 + 추가

오른쪽 위의 추가를 탭하면 — 홈 화면에 한방병원 행정 앱이 생깁니다.

알아두세요 — iOS에서는 반드시 Safari로 열어야 합니다. Chrome·Naver 앱에서는 "홈 화면에 추가" 메뉴가 보이지 않습니다.
